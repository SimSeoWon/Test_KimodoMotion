# 날짜·실행 번호별 영구 진단 로그

- date: 2026-09-19
- status: implemented
- scope: 포즈 LLM, 모션 추론, GLB 내보내기

## 문제

포즈 런타임은 최근 이벤트 30개만 메모리에 보관했고 Claude stderr는 버렸다. 서버가
종료되면 지연과 실패 근거가 사라졌다. 모션 생성도 최종 `meta.json`은 남겼지만 추론과
내보내기 각각의 시간, stdout/stderr, 실패 traceback을 한곳에서 연결해 볼 수 없었다.

## 결정

모든 포즈 조절과 모션 생성 실행에 당일 공통 순번을 할당한다. 로그는
`webui/logs/YYYY-MM-DD/NNNN_<kind>_<id>.jsonl`에 영구 저장하며 git에서는 제외한다.

포즈 로그에는 자연어 명령, 입력 PoseAsset, 전신 스냅샷, Claude 프로세스 PID와 시도 번호,
`init`/`api_retry`/`result` 이벤트, stderr, 구조화 원본 결과, 레시피 적용 후 최종 포즈,
변경 컨트롤, 총 처리 시간과 traceback을 기록한다.

모션 로그에는 전체 요청 파라미터와 키포즈, 확정 seed/backend/steps/model, 추론 명령과
소요 시간 및 stdout/stderr, GLB 내보내기 명령과 소요 시간 및 stdout/stderr, 최종 meta와
traceback을 기록한다. 따라서 느린 단계와 잘못된 포즈 입력을 같은 실행 파일에서 재구성할
수 있다.

## 결정론적 자세 프리셋 제거

자연어에 `마보`/`horse stance`가 들어오면 발·골반·무릎을 고정 수치로 덮어쓰던
`apply_pose_recipe()`를 삭제했다. 이 동작은 사용자가 명시적으로 불러오는 저장 포즈와
별개의 숨은 프리셋이었으며, 포즈 생성·로드 후 요청한 부분만 수정한다는 작업 모델과
충돌했다. 이제 자세 이름에 따른 하드코딩 분기는 없고 현재 포즈와 LLM 결과만 사용한다.

## 포즈 LLM 타임아웃 설정화

진행 이벤트가 계속 들어오는데도 70초마다 Claude를 종료하고 처음부터 자동 재시도하던
고정 정책을 제거했다. `webui/config.json`에서 `total_timeout_seconds`,
`idle_timeout_seconds`, `max_attempts`를 조절한다. 기본값은 총 300초, 이벤트 무응답 45초,
1회 시도다. 설정은 요청 시작마다 다시 읽으므로 파일 변경 뒤 서버를 재시작할 필요가 없다.
전체 Claude 이벤트 payload도 실행 로그에 저장해 rate-limit 상태와 stop reason을 보존한다.

## 위치 목표와 회전 목표 동시 보존

발 위치 목표가 함께 있다는 이유로 같은 다리의 고관절 회전을 삭제하던 후처리를 제거했다.
위치는 보폭과 접지를, 회전은 다리와 발의 방향을 표현하므로 서로 대체할 수 없다. 이 규칙은
LLM이 생성한 20도 외회전을 삭제하고 약 9mm의 발 이동만 남겨, 이력은 바뀌었지만 화면의
모델은 거의 그대로인 허위 성공을 만들었다. 포즈 프롬프트에도 거리·배수·각도를 출력 좌표로
역산해 검증하고, 반올림만 달라진 좌표를 수정으로 간주하지 말도록 명시했다.

요청 크기를 임의로 약화시키던 클라이언트의 고관절·무릎·발목 가동범위 clamp와 뒤꿈치
지면 강제 보정을 우선 제거했다. 프롬프트의 보수적 가동범위 및 modest 지시도 제거했다.
뼈 길이와 부모-자식 연결은 리그 불변 조건이므로 유지한다.

## Claude 작업 지침 명문화

루트 `CLAUDE.md`에 현재 WebUI 포즈 수정 규칙을 추가했다. 저장 포즈와 숨은 프리셋의 구분,
X/Y/Z 좌표계와 Y축 yaw, 한국어 `팔자`의 toes-out 의미, 거리·각도 결과 검증, 위치와 회전의
동시 보존을 명시했다. 기존 `scripts/keypose_mcp.py`는 과거 타임라인 STORE 및 프리셋 API를
사용하므로 현재 작업 포즈의 권위 있는 MCP가 아니며 개편 전에는 활성화하지 않는다고 기록했다.

포즈 에이전트의 최소 모델을 Sonnet으로 올렸다. 기본값은 `sonnet`이며
`KIMODO_POSE_AGENT_MODEL`이 비어 있거나 Haiku를 지정해도 Sonnet을 사용한다.
