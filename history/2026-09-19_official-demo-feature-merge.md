# 공식 kimodo.cpp 데모 기능을 WebUI에 병합

- date: 2026-09-19
- status: implemented
- scope: 모델 선택, 텍스트 인코더 양자화, 상주 생성 워커, 재생 타임라인, 추적 카메라

공식 Go 데모에서 확인한 런타임·재생 기능을 기존 WebUI의 스토리보드, 키포즈, AI 포즈 편집과
합쳤다. 서버는 설치된 motion GGUF와 BF16/Q8/Q6/Q5/Q4 LLM2Vec 후보를 검색해 선택 목록으로
제공하고, 원시 경로 입력은 고급 옵션의 호환·수동 오버라이드로 유지한다.

키포즈, 부정 프롬프트, 비표준 CFG가 없는 요청은 `kmd-generate --server`를 사용해 같은
모델·인코더·백엔드 조합을 메모리와 VRAM에 유지한다. 현재 워커 프로토콜이 표현하지 못하는
요청은 기존 단발 CLI로 폴백해 기능 손실을 막는다. 취소로 워커가 종료되면 다음 요청에서
자동으로 다시 만든다.

생성 결과 메타에는 루트 궤적 URL을 기록한다. 브라우저는 `model-viewer`의 재생 시간을 프레임
슬라이더와 동기화하고, 루트 X/Y/Z를 보간해 선택적으로 카메라 타깃을 따라가게 한다. 기존
스토리보드 구간 타임라인과 별도로 결과 재생/일시정지/처음 이동/프레임 탐색을 제공한다.
