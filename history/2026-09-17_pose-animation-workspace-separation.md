# 포즈·애니메이션 작업공간 분리

- date: 2026-09-17
- status: implemented
- scope: Web UI 포즈 자산 편집과 애니메이션 타임라인 구성의 책임 분리

## 결정

포즈는 시간 정보를 갖지 않는 단일 프레임 자산으로 취급한다. 포즈 생성 창에서는 캐릭터의
관절을 편집하고 이름 있는 포즈 프리셋을 저장하거나 불러오는 일만 한다.

애니메이션 생성 창은 텍스트 프롬프트(또는 스토리보드 구간)와 별도의 포즈 트랙을 소유한다.
사용자는 저장된 포즈를 골라 특정 프레임에 배치하며, 생성 요청 시 텍스트 파라미터와 배치된
키포즈 문서를 함께 전달한다.

## UI 흐름

1. `포즈 생성` 탭에서 시간축 없이 한 자세를 만든다.
2. 자세에 이름을 붙여 포즈 프리셋으로 저장한다.
3. `애니메이션 생성` 탭의 포즈 트랙에서 프리셋과 대상 프레임을 선택한다.
4. 프롬프트/스토리보드 구간과 배치된 포즈를 함께 사용해 애니메이션을 생성한다.

## 호환성

서버와 네이티브 런타임의 기존 `keyposes` 계약은 유지한다. UI 경계에서만 단일 포즈 자산과
프레임 배치를 분리하고, 애니메이션 생성 직전에 기존 schema version 1 문서로 조립한다.
