# 미리보기 캐릭터를 재생 설정으로 분리

- date: 2026-09-19
- status: implemented
- scope: WebUI 모션 생성, 결과 재생, Mixamo 미리보기 GLB

미리보기 캐릭터는 모션 생성 입력이 아니라 동일한 관절 애니메이션을 표시하는 재생기 설정이다.
생성 폼의 캐릭터 선택과 생성 API의 `mixamo_model` 파라미터를 제거하고, 선택기를 결과 재생
타임라인으로 이동했다. 생성 메타도 더 이상 특정 캐릭터를 소유하지 않는다.

사용 편의를 위해 모션 생성 패널에도 같은 표시 설정의 선택기를 둔다. 생성 패널과 재생
타임라인의 선택기는 양방향으로 동기화되지만, 값은 생성 API에 포함되지 않으며 모션 자체에는
귀속되지 않는다.

브라우저가 결과를 열거나 캐릭터 선택을 바꾸면 `/api/preview`에 생성 ID와 캐릭터 ID를
요청한다. 서버는 보존된 raw 모션에서 해당 캐릭터용 GLB를 만들고
`preview_<character>.glb`로 캐시한다. 같은 조합의 다음 요청은 캐시 파일을 바로 사용한다.
기존 `animation.glb`는 캐릭터와 무관한 캡슐 기본 산출물 및 호환 다운로드로 유지한다.

경로 이탈을 막기 위해 생성 ID를 제한하고 `GENERATIONS_DIR` 바로 아래의 `meta.json`이 있는
결과만 허용한다. 캐릭터 ID도 서버가 발견한 목록과 정확히 일치해야 한다.

저폴리 캡슐은 부모-자식 관절 구간을 자식 관절에 강체 스키닝하던 오류가 있었다. 자식 회전이
구간 전체를 먼 끝점 기준으로 돌려 관절이 분리돼 보였으므로, 각 뼈 구간을 실제로 구동하는
부모 관절에 귀속시켰다. 기존의 깨진 캐시를 재사용하지 않도록 미리보기 캐시 버전도 올렸다.
