# 스토리보드 구간별 이미지 캡션

스토리보드의 각 구간에 이미지 파일 입력을 추가했다. 이미지를 고르면 기존
`/api/caption` 엔드포인트와 로컬 BLIP 경로를 재사용해 해당 구간 프롬프트만 채우며,
성공·실패 상태도 그 구간 바로 아래에 표시한다. 일반 단일 프롬프트 이미지 입력과 구간별
입력이 같은 `captionImageFile()` 클라이언트 함수를 사용하므로 요청 형식과 오류 처리가
서로 어긋나지 않는다.

캡션은 최종 모션 파라미터가 아니라 편집 가능한 짧은 초안이다. 사용자가 동작 중심으로
다듬은 뒤 기존 스토리보드 생성 흐름(`segments`)으로 전달한다.
