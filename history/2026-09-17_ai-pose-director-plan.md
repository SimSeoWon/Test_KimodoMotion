# AI 포즈 디렉터 구현 플랜

- date: 2026-09-17
- status: planned
- scope: Web UI 자연어 포징, Claude/Codex 도구 호출, 수동 기즈모 보정 연계
- prerequisite: `2026-09-17_webui-keypose-editor-plan.md`

## 목표

사용자가 애니메이션 관절을 직접 하나씩 조작하지 않고 다음과 같이 연출 의도를 말하면,
Claude 또는 Codex가 현재 캐릭터 상태를 읽고 여러 제어점을 묶어서 초안 포즈를 만든다.

> 하체는 자세를 낮추고 마보 자세를 취해. 상체는 정면을 유지해.

현재 구현된 13개 제어점과 기즈모 편집기는 제거하지 않는다. AI가 만든 초안을 사람이 화면에서
확인하고 세부 자세를 보정하는 정밀 편집기로 사용한다.

최종 작업 흐름은 다음과 같다.

`자연어 지시 → AI 초안 포즈 → 시각적 확인 → 기즈모 미세 조정 → 프리셋 저장 → 타임라인 배치`

## 핵심 원칙

1. LLM은 관절 행렬을 직접 생성하지 않고 이름 있는 13개 제어점에 대한 의도를 구조화한다.
2. 실제 FK, IK, 관절 연결과 좌표 변환은 결정론적인 포즈 엔진이 처리한다.
3. AI 변경과 수동 변경은 하나의 키포즈 문서와 revision/undo 이력을 사용한다.
4. 한 문장의 다관절 변경은 하나의 트랜잭션으로 적용하거나 전부 취소한다.
5. 기즈모는 AI 초안의 검수와 미세 보정 수단으로 유지한다.
6. “조금 더 낮게” 같은 후속 명령은 직전 포즈와 선택된 프레임을 문맥으로 사용한다.
7. 의미 해석 결과와 실제 적용 결과를 분리해 사용자가 적용 전에 검토할 수 있게 한다.

## 사용자 경험

### AI 포즈 디렉터

포징 패널 상단에 다음 요소를 추가한다.

- 자연어 명령 입력창
- 현재 프레임 또는 선택 프레임 범위 표시
- `초안 만들기`, `적용`, `취소` 버튼
- AI가 해석한 동작 요약
- 변경될 제어점 목록과 before/after 값
- 진행 상태와 오류 메시지

예시 해석 결과:

- 골반을 아래로 이동
- 양발 간격 확대 및 지면 고정
- 양 무릎을 굽히고 바깥 방향으로 배치
- 가슴과 고개는 정면 회전 유지
- 좌우 균형과 뼈 길이 유지

### 후속 명령

초안 또는 적용된 결과를 기준으로 다음과 같은 상대 명령을 지원한다.

- 조금 더 낮게
- 무릎을 덜 벌려
- 오른발만 반 보 앞으로
- 상체는 그대로 유지해
- 이 포즈를 좌우 반전해
- 이 결과를 `낮은 마보 자세` 프리셋으로 저장해

## 구조

### 1. 포즈 상태 스냅샷

현재 저장된 키포즈뿐 아니라 편집 중인 실제 본 상태를 AI가 읽을 수 있는 정규화된 스냅샷을
제공한다.

- 프레임과 라벨
- 13개 제어점의 world position/global rotation
- 선택된 제어점
- 고정된 위치/회전 여부
- 캐릭터 기준축과 단위
- 발의 지면 높이, 골반 높이, 좌우 폭 등 유용한 파생값

### 2. 의미 계획 형식

LLM 출력은 자유 형식 좌표가 아니라 검증 가능한 `pose_plan`으로 제한한다.

```json
{
  "summary": "낮은 마보 자세",
  "frame": 24,
  "operations": [
    {"op": "lower", "control": "pelvis", "amount": 0.22},
    {"op": "spread_pair", "controls": ["left_foot", "right_foot"], "amount": 0.28},
    {"op": "bend_pair", "controls": ["left_knee", "right_knee"], "amount": 0.55},
    {"op": "plant_pair", "controls": ["left_foot", "right_foot"]},
    {"op": "preserve", "controls": ["chest", "head"], "rotation": true}
  ]
}
```

좌표가 필요한 경우에도 현재 스냅샷을 기준으로 상대 이동을 우선 사용한다. 절대 world 좌표는
명시적인 배치 요청에만 사용한다.

### 3. 결정론적 포즈 실행기

`pose_plan`을 실제 본 조작으로 바꾸는 실행기를 추가한다.

- 대칭 쌍 연산
- 골반 높이 조절
- 발 간격과 방향 조절
- 손/발 고정
- 팔꿈치/무릎 굽힘 힌트
- 상체 또는 특정 제어점 보존
- 좌우 반전
- 관절 가동 범위 제한
- 충돌하거나 과도한 명령 완화

실행기는 브라우저 편집기와 에이전트/MCP가 동일한 의미를 사용하도록 공용 모듈로 둔다.

### 4. 에이전트 및 MCP

기존 저수준 `move_control`, `rotate_control` 도구는 유지하고 다음 고수준 도구를 추가한다.

- `get_live_pose_snapshot`
- `plan_pose_from_instruction`
- `preview_pose_plan`
- `apply_pose_plan`
- `revise_pose_plan`
- `save_pose_as_preset`

Claude/Codex는 자연어를 해석하고, 서버는 schema 검증과 결정론적 실행을 담당한다. 외부
에이전트 연결이 없는 경우에는 Web UI가 지원되는 포즈 레시피를 직접 실행하는 fallback을
제공한다.

### 5. 프리뷰와 트랜잭션

- AI 결과는 우선 임시 preview layer에 표시한다.
- 적용 전 원본 스냅샷을 보관한다.
- `적용` 시 한 revision으로 저장한다.
- `취소` 시 원본 본 상태로 복원한다.
- 적용 후 기즈모 변경은 같은 키포즈의 다음 revision으로 기록한다.
- undo 한 번으로 AI가 변경한 모든 제어점을 함께 되돌린다.

## 포즈 레시피

LLM이 매번 인체공학을 처음부터 추론하지 않도록 자주 쓰는 자세는 파라미터화된 레시피로
제공한다.

초기 레시피 후보:

- 마보 자세 / horse stance
- 앉기 / 웅크리기
- 걷기 준비 자세
- 달리기 출발 자세
- 양손 들기
- 한 손 가리키기
- 방어 자세
- 물건 들기

`마보 자세` 레시피의 기본 제약:

- 발 간격을 골반/어깨 폭 기준 비율로 확장
- 양발을 지면에 고정
- 골반 높이를 다리 길이 기준 비율로 낮춤
- 양 무릎을 발끝 방향에 맞춰 굽힘
- 골반과 가슴의 과도한 전후 기울기 방지
- 머리와 가슴은 정면 유지
- 좌우 무게중심을 중앙에 유지

레시피는 완성 포즈가 아니라 LLM이 조절할 수 있는 안전한 시작점이다. `조금`, `많이`,
`더 낮게` 등의 표현은 레시피 강도 파라미터로 변환한다.

## 구현 단계

### Phase 1 — 공용 포즈 계획과 실행기

- `pose_plan` schema 및 검증기 작성
- 현재 13개 제어점의 live snapshot 생성
- 상대 이동, 보존, 대칭 쌍, plant 연산 구현
- 마보 자세 레시피 구현
- 연산 전체를 하나의 revision으로 저장
- 단위 테스트로 대칭성, 발 고정, 상체 보존 검증

### Phase 2 — Web UI AI 포즈 디렉터

- 자연어 입력과 프리뷰 패널 추가
- 해석 결과 및 변경 제어점 표시
- 적용/취소/undo 연결
- 적용 결과를 기즈모로 이어서 편집
- 프리셋 저장과 타임라인 배치 연결

### Phase 3 — Claude/Codex 연결

- 고수준 MCP 도구 추가
- 현재 프레임과 live snapshot 전달
- 자연어 → `pose_plan` 도구 호출 지침 제공
- 후속 상대 명령과 revision 충돌 처리
- 에이전트가 없는 로컬 fallback 경로 제공

### Phase 4 — 타임라인과 애니메이션 확장

- 시작/끝 포즈를 자연어로 함께 생성
- 동일 프리셋의 강도 변형 배치
- 두 키포즈 사이 전환 시간과 easing 지정
- 발 미끄러짐 방지를 위한 구간별 plant constraint
- 스토리보드 구간 설명과 포즈 디렉터 연결

## 테스트 및 완료 조건

다음 시나리오가 모두 동작해야 한다.

1. 빈 프레임에서 “하체를 낮추고 마보 자세”를 입력하면 양발·양무릎·골반이 함께 변경된다.
2. 상체 보존 요청 시 가슴과 머리의 방향이 허용 오차 안에서 유지된다.
3. 양발의 높이가 지면에 유지되고 다리 뼈 길이가 바뀌지 않는다.
4. preview 취소 시 본 상태가 완전히 원복된다.
5. 적용 후 undo 한 번으로 AI 변경 전체가 취소된다.
6. “조금 더 낮게”가 직전 결과에 상대적으로 적용된다.
7. AI 결과를 기즈모로 수정한 뒤 프리셋에 저장하고 다른 프레임에 배치할 수 있다.
8. Claude/Codex가 저수준 좌표를 임의 생성하지 않고 `pose_plan`을 통해 조작한다.
9. 잘못된 제어점, NaN, 과도한 관절 범위와 stale revision이 적용 전에 거부된다.
